API vs Local

SEP 2026 · DEMO
PYTHON · FASTAPI · WEBSOCKETS · SQLITE

NOTES

A teaching demo. One app pretends to be a phone streaming accelerometer samples; the other is the telemetry server. Send one API request per sample at 200 Hz with a bit of latency and you watch the queue go red and keep draining long after you hit Stop. Switch to writing a file and uploading once, and the same recording costs one request and no wait.

The last part is reads: open a recording once and it goes to the database, open it again and it comes out of the cache instantly. Three ideas, each one visible as a number moving on screen.
